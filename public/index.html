Before anything runs

Inspection and analysis only read the repository. Code from it runs only if you explicitly start a check, and only inside a disposable sandbox that has been verified, with no network during checks, no access to secrets, and hard limits on time, memory, processes and output. No finding, and no passing check, means the code is safe.

Inspecting: reading metadata, pinning the commit, downloading and checking the source archive, then analysing it. Large repositories take up to a minute.
